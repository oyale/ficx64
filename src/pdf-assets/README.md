# Local PDF assets

- jsPDF 4.2.1: upstream browser UMD distribution, MIT license in LICENSE-jspdf.txt.
- Barlow Regular / SemiBold and Barlow Condensed SemiBold: Google Fonts upstream,
  SIL Open Font License 1.1, included in OFL-Barlow.txt and OFL-BarlowCondensed.txt.
- `sources.json` records downloaded URLs, byte sizes and SHA-256 hashes of the
  unmodified assets. They are committed so builds never download dependencies.

`build.py` embeds the generator, all three fonts and their licenses in the HTML.
It removes the library's source-map URL to avoid an external development request.
Fonts are embedded as subsets in the generated PDF. The document uses jsPDF's
text and vector primitives, with its own pagination; no HTML rasterization or
additional table library is required.

`ficx-mark.png` is a transparent 256px rendering of the approved `icons/mark.svg`,
generated by `scripts/generate_icons.py`. The build embeds it in the HTML and the
PDF; it is local project artwork rather than a third-party asset.
